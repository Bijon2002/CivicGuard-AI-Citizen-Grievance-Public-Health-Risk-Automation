# Hazard Detection & Impact Analysis API

A REST API for the image-based hazard detection project. Given a hazard
(currently via a placeholder — later via a real trained image model), it
returns:
- **Issues** caused directly by the hazard
- **Precautions** to take
- **Byproduct issues** (secondary/knock-on effects)

## 1. Setup

```bash
pip install fastapi uvicorn python-multipart --break-system-packages
```

## 2. Run the API

```bash
cd hazard_api
uvicorn app:app --reload
```

The API will start at: `http://127.0.0.1:8000`

Interactive API docs (auto-generated by FastAPI — great for demos/viva):
`http://127.0.0.1:8000/docs`

## 3. Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/` | Health check |
| GET | `/hazards` | List all hazard types |
| GET | `/hazards/{name}` | Full report for one hazard (e.g. `/hazards/Flood`) |
| POST | `/predict` | Upload an image, get predicted hazard + full report |

## 4. Example Usage

**List hazards:**
```bash
curl http://127.0.0.1:8000/hazards
```

**Get Flood report:**
```bash
curl http://127.0.0.1:8000/hazards/Flood
```

**Upload an image for prediction:**
```bash
curl -X POST "http://127.0.0.1:8000/predict" -F "file=@road_photo.jpg"
```

## 5. IMPORTANT — Connecting the Real Model

The `/predict` endpoint currently uses a **placeholder** function
(`predict_hazard_from_image` in `app.py`) that picks a random hazard. This
lets you build and test the API/front-end before the CNN model is trained.

Once your image classification model (e.g. MobileNetV2/ResNet18 fine-tuned
on Flood / FallenTree / RoadDamage / Accident / NoHazard images) is ready:

1. Load the trained model once when the app starts (not per-request).
2. Replace the body of `predict_hazard_from_image()` in `app.py` with real
   preprocessing + `model.predict(...)` inference.
3. Map the model's output index to the matching class name.

Step-by-step instructions are already written as comments inside
`predict_hazard_from_image()` in `app.py`.

## 6. Extending the System

To add a new hazard (e.g. "Landslide"), just add a new entry to
`hazard_data.json` with `description`, `issues`, `precautions`, and
`byproduct_issues`. No code changes needed in `app.py`.
